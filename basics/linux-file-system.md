# Linux File System

## Common Directories

| Directory | Purpose |
|------------|------------|
| / | Root directory |
| /home | User home directories |
| /etc | Configuration files |
| /var | Variable data and logs |
| /tmp | Temporary files |
| /bin | Essential commands |
| /usr | User programs and utilities |

## Commands

### Print Current Directory

```bash
pwd
```

### List Files

```bash
ls
```

### List Detailed Files

```bash
ls -l
```

### Show Hidden Files

```bash
ls -a
```
